# textexpander menu inventory

Program: `C:\Program Files\Smile\TextExpander\TextExpander.exe`, version 8.4.8 (848.4) as shown in
its About box. The capture script found no window: TextExpander runs from the tray. The user then
sent 27 screenshots of the desktop app and 12 of the web dashboard (2026-10-25). Everything below is **observed** from them. The account's name,
e-mail address, picture and workspace name are visible in some screenshots and are left out here.

## Tray menu
Open TextExpander · Disable Expansion · New Snippet · New Snippet from Clipboard · Edit Last
Expanded Snippet · Preferences · Help ▸ · Check for Updates... · Sign Out · Exit.

## Main window
Left: search box, "new group" button, a tree with **Just Me** (groups) and **Public** (add public
groups). Right, when nothing is selected: "Search right where you type. Type Ctrl+/ to use the
inline search hotkey and search for snippets right next to where you're typing."
Account menu at the bottom left: Preferences, Manage my Team, Statistics, My Profile, Help,
Submit an Idea!, Sign Out.

### Menu bar
- **File**: New Snippet Ctrl+N · New Group Ctrl+Shift+N · Add Public Group... · New Snippet from
  Clipboard · Edit Last Expanded Snippet · Duplicate Ctrl+D · Print All Groups... · Print Selected
  Groups... · Preferences Ctrl+, · Check for Updates... · Disable Expansion · Sign Out · Exit Ctrl+Q.
- **Edit**: Cut · Copy · Paste · Paste and Match Style Ctrl+Shift+V · Delete · Find Ctrl+F.
- **View**: Show Snippet Preview Ctrl+Enter · Sort by Content / Abbreviation / Label / Date
  Modified · Sort Ascending / Descending.
- **Help**: TextExpander Help · Contact Support · Logging ▸ · About.

### Group
Context menu: Paste · Duplicate · Share (opens the web site) · Group Settings · Delete Snippet Group.
Group Settings: Name · Notes · Expand in (default from Preferences) · Expand when (whitespace
precedes abbreviation) · **Group prefix**.

### Snippet editor
Content Type (Plain Text, formatted, script) · toolbar: date, time, fill-in, key, cursor position,
clipboard, script · Label · Abbreviation · Case: Case Sensitive / Ignore Case / Adapt to Case of
Abbreviation.

## Preferences
Pages: Expansion · Suggestions · Hotkeys · Appearance · Update · Account.

1. **Expansion**: Expand abbreviations; Expansion Mode: Immediately When Typed / At Delimiter (Keep
   Delimiter) / At Delimiter (Abandon Delimiter); Delimiters: Space, Return, Enter, Tab by default,
   plus Esc and punctuation/symbol keys (Show All Delimiters, Select Default Delimiters); When
   Expanding: Play sound, Run script snippets, Restore clipboard, Paste timeout 0.2 s; Default Case
   Sensitivity; Expand snippet groups when typing in: all applications / all applications,
   except... / only these applications...
2. **Suggestions**: Suggest snippets based on my typing habits ("TextExpander does not store what
   you type"); Scan typing for suggestions when typing in: all applications / all applications,
   except... / only these applications...; Notify me about snippet suggestions; Notify me of the
   abbreviation when I type a snippet that already exists.
3. **Hotkeys** (each "Set hotkey" with a reset button): Open TextExpander · Enable/Disable
   TextExpander · Create new Snippet · Create new Snippet from clipboard · Edit last expanded
   Snippet · Inline search **Ctrl+/** · Quick actions **Ctrl+Shift+/**. The set dialog says "Press
   the Hotkey you wish to use now … You can use any combination of Ctrl, Alt & Shift with your key."
4. **Appearance**: display font and size for plain text snippets (Arial 12) and for formatted text
   snippets (Arial 12), each with a preview box.
5. **Update**: Using Version 8.4.8; last checked; Check for Updates; Check for updates hourly /
   daily / weekly / monthly / never; Include anonymous system profile information; Include beta
   versions. "You're up to date!" dialog.
6. **Account**: sign-in status, snippet and group counts, Sign Out, Manage Account on the web site.

## Web dashboard (textexpander.com)
Left menu: Get Started · Snippets · Snippet Activity · Snippet Requests · Statistics · Members ·
Teams · Import/Export · Settings. This is TextExpander's online service, not part of the desktop
app. Observed from 12 more screenshots (the user's own group names are left out):
- **Snippets**: tabs My groups / Organization groups; search; sort; Create group; columns Name,
  Organization; per group "share with people" and delete (own groups) or unsubscribe (public groups).
- **Snippet Activity**: Refresh, Filter, Date Range (Last 24 hours); columns Date/Time, Person,
  Activity, Snippet Group, Abbreviation, Label.
- **Snippet Requests**: tabs Assigned to you / All requests; Refresh; Filter (Status Open, Assigned
  to You).
- **Statistics**: tabs Personal / Organization; Report (Overview, Snippets, Data export); Date
  range; **Words Per Minute 50**; Generate report; charts Snippets Expanded and Time Saved; Daily
  Activity table (Date, Time Saved, Snippets) with an export button.
- **Members**: Invite your team, Add Members (organization name, team size).
- **Teams**: Create a Team (name).
- **Import/Export**: Import up to 10 files at a time. Supported formats: CSV (.csv), TextExpander
  files (.textexpander), ShortHand export files (.txt), Instant Text glossary files (.glo), Google
  Sheets HTML exports (.html), macOS Text Replacements (.plist). Tips: CSV columns are
  abbreviation, snippet, optional label; quoted values can span lines. Export: one download per
  snippet group you can edit.
